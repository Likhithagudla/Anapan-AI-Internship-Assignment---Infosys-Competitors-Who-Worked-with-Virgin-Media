# 🔍 Infosys Competitor Collaboration Tracker

A lightweight, responsive web tool that helps Infosys identify which of their competitors have collaborated with Virgin Media. Built as part of the Anapan AI internship assignment.

---

## 💡 Project Overview

Before approaching a target client (Virgin Media), Infosys wants to analyze which of its competitors have previously worked with them. This tool provides:

- A curated list of verified collaborations
- Links to public sources (articles, announcements, press releases)
- A simple UI for filtering and downloading the data

---

## ✨ Features

- ✅ One-click collaboration scan
- 🔍 Real-time keyword/competitor search
- 📄 Export results to CSV
- 🎨 Responsive dark-mode design
- 🕒 Timestamp included (last updated date)
- ⚡ Pure HTML + CSS + JavaScript (no backend required)

---

## 🚀 How to Use

1. Click **Run Collaboration Search**
2. View the table of competitors and their work with Virgin Media
3. Use the search bar to filter entries
4. Click **Download CSV** to save the data

---

## 🛠️ Tech Stack

- HTML5
- CSS3
- JavaScript (Vanilla)
